# MOV3 Analytics Enterprise

Piattaforma Scientifica di Performance Intelligence, Prevenzione Clinica e Match Analysis per il Tennis d'Élite.

## Architettura e Moduli
- **Executive Locker Room**: panoramica di squadra, readiness a 2 giorni e focus atleta 1-click.
- **Analisi GPS Tennis**: match analysis, sessioni, microcicli settimanali e macrocicli stagionali.
- **Area Medica & Fisioterapia**: master calendar integrato, diario clinico, prevenzione e allerta tetto 70%.
- **Test Fisici & Valutazione Neuromuscolare**: pedane di forza, fotocellule, dinamometria e ROM.
- **Portale Atleta Mobile**: compilazione giornaliera Wellness mattutino e carichi sRPE (Foster).
- **Refertazione PDF Ufficiale**: generazione referti vettoriali ReportLab A4 Landscape.

## Setup e Requisiti
- Python >= 3.9
- Database: Supabase (PostgreSQL 15)
- Dipendenze: consultare `requirements.txt`
